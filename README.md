# 🚀 Condicionais em Java

Projeto desenvolvido para praticar conceitos fundamentais de **estruturas condicionais em Java**, utilizando instruções `if`, `else if`, `else` e operadores ternários.

## 📚 Sobre o Projeto

Este repositório contém uma série de exercícios voltados ao aprendizado da lógica de programação e tomada de decisões em Java.

Os exemplos abordam situações como:

- Verificação de números pares e ímpares
- Identificação de números positivos, negativos ou zero
- Cálculo de preços com base em condições
- Classificação de notas
- Determinação de estações do ano
- Outras aplicações práticas de estruturas condicionais

## 🛠️ Tecnologias Utilizadas

- Java
- Scanner (entrada de dados pelo teclado)
- Estruturas Condicionais (`if`, `else if`, `else`)
- Operador Ternário (`? :`)

## ▶️ Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/Condicionais-Java.git
```

### 2. Acesse a pasta do projeto

```bash
cd Condicionais-Java
```

### 3. Compile o exercício desejado

```bash
javac ex1.java
```

### 4. Execute o programa

```bash
java ex1
```
